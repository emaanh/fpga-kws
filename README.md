# fpga-kws

Keyword spotting on an FPGA (Digilent Nexys A7-100T). A small depthwise-separable CNN
(DS-CNN-S, 23k params) is trained in PyTorch on Speech Commands v2, quantized to int8 with
power-of-two scales, and runs in hand-written SystemVerilog.

12 classes: silence, unknown, yes, no, up, down, left, right, on, off, stop, go.

| Model | Test accuracy |
|---|---|
| Float | 94.95% |
| int8, integer-only reference | 94.95% |
| RTL (simulation, bit-exact to the reference) | matches |

The engine uses 16 parallel MACs: 665k cycles (6.65 ms at 100 MHz) per inference. On the
xc7a100t it uses ~5.8k LUTs, ~4k FFs, 43 RAMB18 and 17 DSP48 (nextpnr-xilinx, 115 MHz estimated).

## Layout

- `python/kws/` data pipeline, log-mel frontend, model, training, QAT, integer reference, export
- `rtl/` inference engine (`kws_engine.sv`), board top level (`kws_top.sv`: UART, LEDs,
  7-segment display); `rtl/gen/` is generated by `kws.export`
- `constraints/` Nexys A7-100T pins
- `tests/` cocotb testbenches (Verilator): engine vs reference, and end-to-end over UART
- `scripts/` bitstream build (openXC7) and Vivado timing check

## Usage

```sh
uv sync
uv run python -m kws.data      # download Speech Commands v2 (~2.3 GB) and build the cache
uv run python -m kws.train     # float training (~8 min on an M-series Mac)
uv run python -m kws.qat       # int8 QAT + integer-only evaluation
uv run python -m kws.export    # ROM hex files, SV package, golden vectors

uv run pytest tests/                                 # RTL vs integer reference (needs verilator)
KWS_N_CLIPS=all uv run pytest tests/test_engine.py   # whole test set (~1 h)

scripts/build_bitstream.sh           # build/bit/kws_top.bit with openXC7 (~45 s)
scripts/build_bitstream.sh program   # build and load over JTAG (openFPGALoader)
uv run python -m kws.host            # run the test set on the board over USB-UART

vivado -mode batch -source scripts/vivado_synth.tcl  # optional Vivado timing sign-off
```

The bitstream flow needs sv2v, yosys and openFPGALoader (Homebrew) plus nextpnr-xilinx,
prjxray and an xc7a100t chipdb under `$OPENXC7` (default `~/tools/openxc7`).

Board protocol (1 Mbaud 8N1): send `'I'` + 1960 int8 features; the board replies `'R'`,
the class index and 12 little-endian int32 logits, and shows the word on the 7-segment
display.
